# Juris Talent MVP

French-first bilingual MVP website for Juris Talent, built with Next.js App Router, TypeScript, Tailwind CSS, and front-end-only form validation.

## Local Development

Install dependencies with your preferred Node package manager, then run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000/fr`.

## MVP Scope

- Public bilingual routes under `/fr` and `/en`
- Brand tokens and shared layout
- Header, footer, language toggle, mobile navigation
- Homepage, student, law firm, opportunities, application, request, about, contact, and legal pages
- Mock opportunities
- Front-end-only form validation and success states

No authentication, dashboards, Supabase connection, real backend, or real CV storage is implemented in this MVP.
